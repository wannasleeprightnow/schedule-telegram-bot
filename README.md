# Telegram-бот расписания Академии

Бот читает публичную Google-таблицу, объединяет недельное расписание с датированными изменениями и фактическими залами. Telegram работает через Long Polling. База данных не используется.

## Запуск

Скопируйте `.env.example` в `.env`, задайте `BOT_TOKEN` и не более пяти ID в `TELEGRAM_USER_IDS`. Запустите `docker compose up --build` либо установите зависимости и выполните `python -m src.main`.

Бот предлагает профиль из классов и курсов, найденных в книге, а затем просит выбрать пол для сопоставления занятий с залами. Выбор пола не заменяет учебную группу: при назначении зала бот ищет запись в листе `Залы` по дате, паре, классу/курсу, группе, предмету и преподавателю, если он известен. Пользователь может запросить расписание на сегодня или ввести дату `ДД.ММ.ГГГГ`; в настройках можно включить ежедневное уведомление на следующий учебный день.

## Данные и обновление

Профили находятся в `data/users.json`. XLSX и время его загрузки — в `data/cache/`. Кэш обновляется раз в 180 секунд. Старый XLSX используется при ошибке загрузки, только если в `.env` явно указано `ALLOW_STALE_CACHE=true`; сообщение об устаревших данных добавляется к расписанию.

`OPENROUTER_API_KEY` и `OPENROUTER_MODEL` необязательны. При отсутствии LLM детерминированный парсер продолжает работу и показывает неоднозначные изменения отдельно.

## Тесты

Установите тестовые зависимости командой `pip install -e '.[test]'`, затем запустите `pytest`. Реальная книга лежит в `tests/fixtures/`.
